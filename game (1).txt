CAR DODGE GAME - INSTRUCTIONS
================================
(Desktop 2-Player + Mobile Portrait Solo + Win Score + Leaderboard +
 Sound + QR Code)

FILES:
  - car_game.py       (Streamlit app that embeds the game)
  - requirements.txt  (tells Streamlit Cloud what to install — just "streamlit")

LAYOUTS
-------
  - DESKTOP / wide screens: same-keyboard 2-player split screen
    (Player 1: A/D/W/S, Player 2: arrow keys).
  - MOBILE / phones (narrow screens): a single, full-width PORTRAIT
    canvas, solo play. Swipe to steer and change speed.
The app switches between these automatically based on screen width —
no setting to change.

NOTE ON CROSS-DEVICE MULTIPLAYER
------------------------------------
An earlier version let two separate phones connect to each other over
a peer-to-peer connection to race head-to-head. That has been removed
— mobile is now solo only, since the connection setup (room codes,
network dependency, occasional connection failures) added complexity
without being reliable enough. If you'd like a two-phone mode again in
the future (either peer-to-peer or with a proper shared backend), just
ask.

WHY NO PYGAME
--------------
Streamlit Cloud runs on a headless server (no display), so pygame
(which needs a real graphics window) can never work there. This game
is built entirely with HTML5 Canvas + JavaScript and embedded into the
Streamlit page, so everything runs in the visitor's own browser.

HOW TO RUN LOCALLY
-------------------
1. pip install streamlit
2. streamlit run car_game.py
3. Your browser opens at http://localhost:8501
   (resize the browser window narrow, or use dev tools' device
   toolbar, to preview the mobile/portrait layout)

HOW TO DEPLOY ON STREAMLIT CLOUD
----------------------------------
1. Push car_game.py and requirements.txt to your repo (replace the old
   files).
2. Streamlit Cloud will auto-redeploy. If it doesn't pick up changes,
   use the app menu (⋮) → Reboot app.
3. Open your app URL — it'll look like
   https://your-app-name.streamlit.app

HOW TO GET THE QR CODE
------------------------
1. Deploy your app (or run it locally on a phone-reachable address —
   see below) and copy its URL.
2. Open the app, look at the left sidebar, "📱 Play on your phone".
3. Paste the URL into the "App URL" box — a QR code appears instantly.
4. Click "⬇️ Download QR code" to save it as a PNG to share or print.

Testing on a phone on the SAME WI-FI without deploying:
  1. Run: streamlit run car_game.py
  2. Find your computer's local IP (Mac/Linux: `ifconfig` or
     `ipconfig getifaddr en0`; Windows: `ipconfig`).
  3. In the sidebar QR box, enter e.g. http://192.168.1.23:8501
  4. Scan with a phone on the same Wi-Fi network.

HOW TO PLAY — DESKTOP
------------------------
1. (Optional) Type each player's name.
2. Set "Score to win" (default 300).
3. Click "Start Race" — this also unlocks sound.
4. Player 1: A/D/W/S. Player 2: arrow keys. Space pauses both. Enter
   restarts once the race is over.
5. Race ends when either player hits the target score, or both crash
   (higher score wins in that case). Scores save to the leaderboard
   automatically.

HOW TO PLAY — MOBILE
------------------------
1. Enter your name.
2. Set "Score to win" if you like (default 300).
3. Tap "▶ Start Race" — this also unlocks sound.
4. Swipe left/right on your car's track to steer, swipe up/down to
   speed up or slow down.
5. The run ends when you hit the target score (a win) or crash. Your
   score is saved to the leaderboard automatically. Tap Start Race
   again to try again.

ABOUT THE LEADERBOARD (IMPORTANT)
-----------------------------------
The leaderboard is stored per-device in the browser's "localStorage".
It will:
  - persist across reloads and future visits on the SAME device
  - NOT be shared between different players' devices
  - NOT sync across devices

If you want one real SHARED leaderboard everyone sees, that needs a
small backend to store scores centrally — e.g. a Google Sheet via
`gspread`, a hosted database like Supabase/Firebase, or a small custom
API. Ask me if you'd like help wiring one up.

TROUBLESHOOTING
-----------------
- Mobile layout not showing? It switches automatically based on
  screen width (700px breakpoint). Try resizing the browser window or
  actually opening it on a phone.

- No sound? Tap/click "Start Race" first — browsers block audio until
  a user gesture. Check the sound toggle too.

- QR code not showing? Make sure you typed a full URL starting with
  http:// or https:// in the sidebar box.

CUSTOMIZING
-------------
Open car_game.py:
  - Mobile breakpoint: `window.matchMedia("(max-width: 700px)")` —
    search for this string (appears twice) to change when the layout
    switches.
  - Default win score: `value="300"` on winScoreInput / mWinScore.
  - Canvas size: width="340" height="600" on the <canvas> tags.
  - Colors: COLORS / OBSTACLE_COLORS near the top of <script>.
  - Difficulty: PlayerGame.reset() — baseSpeed and spawnInterval.
