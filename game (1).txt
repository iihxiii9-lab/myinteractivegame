CAR DODGE GAME - INSTRUCTIONS (2 Player + Win Score + Leaderboard + Sound + QR Code)
======================================================================================

FILES:
  - car_game.py       (Streamlit app that embeds the game)
  - requirements.txt  (tells Streamlit Cloud what to install)

WHAT'S NEW
----------
  - QR CODE: a sidebar panel ("📱 Play on your phone") where you paste
    your app's live URL and instantly get a scannable QR code, plus a
    download button to save it as an image (e.g. to print or share).
  - WIN SCORE: set a target score before starting. First player to
    reach it wins instantly and the race ends for both players. If
    both players crash before anyone reaches the target, whoever had
    the higher score is recorded as the winner.
  - 2-PLAYER split screen, same keyboard:
        Player 1: A/D to steer, W/S for gas/brake
        Player 2: Left/Right arrows to steer, Up/Down arrows for gas/brake
  - CAR SOUNDS: synthesized in the browser with the Web Audio API
    (no audio files needed) — engine hum, crash noise, victory fanfare.
  - LEADERBOARD: top 10 scores, saved automatically once the race ends.
  - Name fields accept any letters, including w/a/s/d and arrow keys —
    typing is no longer blocked by the game's keyboard listener.

WHY NO PYGAME
--------------
Streamlit Cloud runs on a headless server (no display), so pygame
(which needs a real graphics window) can never work there. This game
is built entirely with HTML5 Canvas + JavaScript and embedded into the
Streamlit page, so everything runs in the visitor's own browser.

HOW TO RUN LOCALLY
-------------------
1. pip install -r requirements.txt
2. streamlit run car_game.py
3. Your browser opens at http://localhost:8501

HOW TO DEPLOY ON STREAMLIT CLOUD
----------------------------------
1. Push car_game.py and requirements.txt to your repo (replace the old
   files). No other files are needed.
2. Streamlit Cloud will auto-redeploy.
3. Open your app URL — it'll look like
   https://your-app-name.streamlit.app

HOW TO GET THE QR CODE
------------------------
1. Deploy your app (or run it locally on a phone-reachable address —
   see below) and copy its URL.
2. Open the app, look at the left sidebar, "📱 Play on your phone".
3. Paste the URL into the "App URL" box.
4. A QR code appears immediately — anyone can scan it with their
   phone's camera app to open the game.
5. Click "⬇️ Download QR code" to save it as a PNG you can share,
   print, or post anywhere.

Testing on a phone on the SAME WI-FI without deploying:
  1. Run: streamlit run car_game.py
  2. Find your computer's local IP address (e.g. on Mac/Linux:
     `ifconfig` or `ipconfig getifaddr en0`; on Windows: `ipconfig`).
  3. In the sidebar QR box, enter something like:
         http://192.168.1.23:8501
     (replace with your actual local IP)
  4. Scan the QR code with a phone connected to the same Wi-Fi network.

HOW TO PLAY
------------
1. (Optional) Type each player's name in the two name boxes.
2. Set "Score to win" (default 300).
3. Click "Start Race" — this also unlocks sound (browsers require a
   click before audio is allowed to play).
4. Player 1 uses A/D/W/S, Player 2 uses the arrow keys.
5. The race ends the moment either player's score hits the target, or
   the moment both players have crashed — whichever comes first.
6. Space bar pauses both games. Enter restarts once the race is over.
7. Final scores are saved to the leaderboard automatically.
8. Click "Clear" next to the leaderboard heading to wipe it.
9. Use the sound button to mute/unmute engine, crash, and win sounds.

ABOUT THE LEADERBOARD (IMPORTANT)
-----------------------------------
The leaderboard is stored in the browser's "localStorage" — meaning
it lives on that specific browser/device only. It will:
  - persist across page reloads and future visits on the SAME browser
  - NOT be shared between different visitors to your deployed app
  - NOT sync across devices

If you want a real SHARED leaderboard all visitors see, that needs a
small backend to store scores centrally (e.g. a Google Sheet via
`gspread`, a hosted database like Supabase/Firebase, or a small custom
API). Ask me if you'd like help wiring one up.

TROUBLESHOOTING
-----------------
- No sound? Make sure you clicked "Start Race" first — browsers block
  audio until a user click. Check the sound toggle and system volume.

- Keyboard doesn't respond in the game? Click on the game canvas area
  (not inside a text box) first so it has focus.

- QR code not showing? Make sure you typed/pasted a full URL starting
  with http:// or https:// into the sidebar box.

- Phone can't reach a locally-run app? Your phone and computer must be
  on the same Wi-Fi network, and your computer's firewall must allow
  incoming connections on port 8501.

CUSTOMIZING
-------------
Open car_game.py:
  - Default win score: `value="300"` on the winScoreInput field inside
    GAME_HTML.
  - Canvas size: width="340" height="600" on the <canvas> tags.
  - Colors: COLORS / OBSTACLE_COLORS near the top of the <script>
    section.
  - Difficulty: PlayerGame.reset() — baseSpeed (starting speed) and
    spawnInterval (frames between obstacles; it also decreases
    automatically over time in update()).
